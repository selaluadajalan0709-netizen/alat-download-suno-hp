01 — Kantong Token

BELUM LOGIN
CARA AMBIL TOKEN (HP & PC)
Pasang sekali aja (pakai Bookmarklet):
  1. Ketuk tombol COPY KODE BOOKMARKLET di bawah.
  2. Buka suno.com di Chrome/Safari HP, login, lalu Bookmark halaman itu (ikon bintang).
  3. Masuk menu Bookmarks → Edit bookmark tadi, ganti nama jadi Ambil Token Suno, lalu hapus URL-nya dan paste kode di bawah, terus Save.

Penting: kode di atas dipasang di BOOKMARK browser — jangan ditempel di kolom token. Yang ditempel di kolom token cuma hasil tokennya (mulai dengan "eyJ").

Cara pakainya tiap mau ambil token: buka tab suno.com → ketuk kolom alamat (URL bar) → ketik Ambil Token Suno → klik saran bookmark berikon bintang (jangan tekan Enter). Token otomatis ter-copy, balik ke sini lalu ketuk PASTE & LOGIN!
Buka suno.com, login. Tekan F12 (DevTools) → tab Network. Klik request apa saja ke studio-api-prod.suno.com. Di Request Headers cari authorization: Bearer eyJ… Copy bagian eyJ… saja (tanpa kata "Bearer"), paste di bawah. Token Suno aktif sekitar 1 jam — kalau daftar lagu kosong/401, ambil token baru.
